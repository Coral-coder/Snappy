Install the native app Use the web app instead
  1. Open this page in Safari on the iPhone itself — not on a Mac, and not inside another app's browser.
  2. Tap Install, then confirm.
  3. First launch: Settings → General → VPN & Device Management → trust the developer.

Nothing happens on tap? The device's UDID is not in the ad hoc provisioning profile, or no signed build has been released yet. The web app above needs none of that — add it to your home screen and it behaves like an app.
